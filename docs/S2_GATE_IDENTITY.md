# S2 GATE IDENTITY MATRIX — Math Hub entrances (design-first record)

Date: 2026-09-22. Scope: VISUAL IDENTITY of the 10 entrances only. The hub is
a selection space; gates are ENTRY PORTALS (portal + identity + sign + entry
point), never micro-worlds, never gameplay. Layout stays S1 (arc/courtyard).

## Design principles (GitHub-first, reference-only)

- Y. Nizan / level-up "World -> innerWorlds" model: a gate is a promise of a
  child world, not the world — REFERENCE (already the project's model).
- Unity URP stylized samples (prior knowledge): silhouette-first staging —
  REFERENCE. Preschool landmark rule (Kenney/Quaternius style guides): one
  legible shape per identity, no fine detail at 15 m — ADAPT.
- No imports; existing CC0 kits + primitives only.

## Hard rules applied

- NO text dependency: every gate keeps its name pill as reinforcement only —
  the crown/legs/arch silhouette carries the identity (TEST A).
- NO gameplay in the hub: all gate geometry collider-free, no interactables,
  no quests, no NPC, no mini-activities (P42/P45 pins enforce).
- One primary visual idea per gate: crowns are single legible shapes at
  2.4-3.6 m so a 4-year-old reads them from the courtyard camera.
- Threshold grammar (all 10): tinted accent ring on the ground under the arch
  + paired cartoon legs + cross-span = unmistakable entrance opening.
- Colour: one accent per gate, shared sand/wood/stone base so the hub stays a
  coherent courtyard (no rainbow park).

## Camera-first validation viewpoints (STANDALONE, human review)

A. Hub overview from the lobby: 10-gate arc reads as one system.
B. Approach: each gate grows clearer as the child walks toward it.
C. Entry: standing at the mouth — clear opening, threshold ring, crown.
D. Wide shot with several gates in frame: no gate reads as random object.
Checklist Q1-Q11 in the S2 brief are answered by the human reviewer.
