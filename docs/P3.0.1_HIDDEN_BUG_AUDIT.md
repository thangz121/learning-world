## 3. Scene audit

  travelling; unload verified (`scenes=2` after return, every run).
- No scene loaded twice (UnitySceneOps short-circuits `IsLoaded`), no unload
  before warp, no stale scene references observed.
- Failure paths: `WorldTransition` returns to Idle/InSubject truthfully; the
  travel/return fail branches restore Main presentation, bounds, HUD and input

  now `Children` on the root surface — Math geometry only. The Main navmesh is
  independent and persists (J3).
