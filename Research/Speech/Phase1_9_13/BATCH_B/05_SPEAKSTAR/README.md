# BATCH B · SYSTEM 05 — SpeakStar (sakura5.app)

STATUS: **UNRELEASED ("soon")** → playtest not possible. Product design fully described (E1).

Exact match to the phase brief: Vietnamese children, English speaking practice, **free and
fully offline**, on-device scoring.

Documented design (E1):
- "Say it and be scored": child taps mic, reads sentence; each word coloured —
  **heard / nearly heard / not heard** — with **0–3 stars** per attempt; all on-device.
- 24 lessons, 4 levels: listen to a short dialogue → say every sentence scored → read a passage.
- **All 44 English sounds**: full IPA chart with an **animated mouth**, one practice sentence per
  sound; reference recordings by phoneticians (not TTS).
- Read-aloud passages + 6 songs with word-by-word highlighting (work with no microphone).
- Vietnamese throughout the UI; English practice material.
- **Nothing collected: no account, no ads, no analytics, no third-party SDKs, no network
  requests; 476 recordings bundled; works with the internet off.**
