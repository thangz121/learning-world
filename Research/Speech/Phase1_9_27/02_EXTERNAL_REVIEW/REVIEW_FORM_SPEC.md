# REVIEW FORM SPEC — WP-1.9.27 Part 3

> **Tóm tắt (VI):** Đặc tả form review: các trường bắt buộc, giá trị hợp lệ, hành vi UI
> (submit/resume/export/duplicate), và những gì bị ẩn khỏi reviewer.

## 1. Record schema (one record per candidate x reviewer)

| field | required | values | note |
|---|---|---|---|
| reviewer_id | yes | e.g. REV-A / REV-B | typed once in the UI |
| blind_id | yes | R### (Pack R) or P27-### (Pack P) | server-assigned |
| label | yes | PRESENT / ABSENT / UNCERTAIN | submit blocked without it |
| confidence | yes | HIGH / MEDIUM / LOW | submit blocked without it |
| assessable | yes | ASSESSABLE / NOT_ASSESSABLE | defaults to ASSESSABLE |
| note | no | free text (<=500 chars) | what you heard / alternatives |
| ts | yes | ISO-8601 UTC | generated by the client |

Server store: `artifacts/reviews/<reviewer_id>.jsonl` (append-only; one JSON object per line).

## 2. UI behavior (verified by QA: 21/21 PASS)

- Candidate presentation: per-reviewer deterministic shuffle (stable across reloads; different
  across reviewers).
- Submit: `POST /api/submit`; returns 200 on store; returns 409 on duplicate unless
  `overwrite=true` (the UI ignores changes after submit to protect blinding history).
- Resume: `GET /api/progress` returns the reviewer's submitted blind_ids; the UI skips them.
- Export: `GET /api/export?reviewer=ID&fmt=json|csv`; CSV header =
  `blind_id,label,confidence,assessable,note,ts`.
- Isolation: reviewers are separate files; B cannot read A's progress.

## 3. What the reviewer must NOT see

- machine_max_A / alt_max_A / machine rank / machine margin / blank statistics
- production_decision, acceptance result, failure classification
- pool, purpose, selection_reason, historical label, TYPE-B status, expected outcome
- other reviewers' labels or progress

The blind payload contains exactly: `blind_id`, `word`, `target_phone`.

## 4. What the coordinator may see (analysis side only)

The coordinator CSV (`REVIEW_CANDIDATES.csv`, and `PILOT_REVIEW_CANDIDATES.csv` for the pilot)
contains the machine-side columns and MUST NOT be handed to reviewers.

## 5. Completion criteria

- All candidates attempted or explicitly NOT_ASSESSABLE.
- Export CSV sent to the coordinator.
- If a reviewer stops early: partial export is valid; record coverage per reviewer.
